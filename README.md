# نردباز – NARDBAZ 🎲

بازی تخته‌نرد دوبعدی فارسی با قوانین کامل، حریف هوشمند در سه سطح، بازی دونفره‌ی آفلاین و آموزش قدم‌به‌قدم تعاملی. کاملاً آفلاین کار می‌کند و روی اندروید (APK) نصب می‌شود.

## ویژگی‌های اصلی

- تخته‌ی چوبی دوبعدی با ۲۴ خانه، Bar، سینی خروج، تاس و انیمیشن حرکت مهره‌ها
- لمس مهره ← لمس مقصد، یا کشیدن مهره با انگشت (Drag & Drop)
- نمایش خانه‌های مجاز، پیام فارسی هنگام حرکت غیرقانونی، دکمه‌ی راهنما و بازگشت حرکت
- قوانین استاندارد: تاس آغازین، جفت (چهار حرکت)، اجبار استفاده از هر دو تاس، اولویت عدد بزرگ‌تر، زدن، Bar، خارج کردن، گامون (۲ امتیاز) و بک‌گامون (۳ امتیاز)
- هوش مصنوعی: آسان، متوسط و سخت (Expectiminimax دو لایه، Pip Count، خانه‌های بسته و مهره‌ی تنها). هوش مصنوعی فقط از حرکت‌های قانونی انتخاب می‌کند و روی تاس دخالتی ندارد.
- آموزش ۶ فصلی با تخته‌ی واقعی (۲۱ درس) و ۱۲ تمرین موضوعی با توضیح پس از هر تمرین
- ذخیره‌ی خودکار بازی، آمار برد و باخت، پیشرفت آموزش و تنظیمات؛ پشتیبان‌گیری و بازیابی
- صدا (با WebAudio و بدون فایل خارجی)، تم تیره و روشن، سرعت انیمیشن، حالت عمودی و افقی

## فناوری‌ها

HTML5 / CSS3 / JavaScript (ES Modules)، گرافیک برداری SVG، Vite، Capacitor (اندروید)، GitHub Actions. منطق قوانین (`src/rules`)، هوش مصنوعی (`src/ai`)، گرافیک (`src/game`) و رابط کاربری (`src/ui`) کاملاً جدا از هم‌اند.

> **نکته‌ی صادقانه:** برای گرافیک به‌جای Phaser از SVG استفاده شده است (تمام عناصر برداری و دوبعدی‌اند). دلیلش این بود که بازی باید در همان محیط ساخت، واقعاً اجرا و آزمایش می‌شد و آن‌جا امکان نصب Phaser نبود. چون گرافیک از منطق جداست، در صورت تمایل می‌توان بعداً لایه‌ی نمایش را با Phaser عوض کرد.

## اجرای نسخه‌ی وب (برای کسی که برنامه‌نویس نیست)

1. از [nodejs.org](https://nodejs.org) نسخه‌ی LTS (۲۲ یا بالاتر) را نصب کنید.
2. پوشه‌ی پروژه را باز کنید و در نوار آدرس پوشه، `cmd` بنویسید و Enter بزنید.
3. این دو دستور را به‌ترتیب اجرا کنید:

```
npm install
npm run dev
```

4. آدرسی که چاپ می‌شود (مثلاً `http://localhost:5173`) را در مرورگر باز کنید.

برای اجرای آزمایش‌های قوانین: `npm test`

## قرار دادن پروژه در GitHub

مخزن شما همین حالا ساخته شده است. اگر فایل‌ها را روی کامپیوتر دارید: در صفحه‌ی مخزن در GitHub روی **Add file ← Upload files** بزنید، همه‌ی فایل‌ها و پوشه‌ها (به‌جز `node_modules`) را بکشید و **Commit changes** را بزنید.

## ساخت APK با GitHub Actions

1. در صفحه‌ی مخزن به تب **Actions** بروید.
2. گردش‌کار **«ساخت APK اندروید»** با هر Push به شاخه‌ی `main` خودکار اجرا می‌شود. برای اجرای دستی: روی آن کلیک کنید ← **Run workflow**.
3. حدود ۱۰ تا ۱۵ دقیقه صبر کنید تا علامت سبز بیاید.
4. روی همان اجرا کلیک کنید و در پایین صفحه در بخش **Artifacts** فایل **Nardbaz-Android** را دانلود کنید. داخل آن فایل `Nardbaz-Android.apk` است.

> اولین اجرا: چون فایل `package-lock.json` هنوز در مخزن نیست، گردش‌کار آن را می‌سازد و به‌صورت Artifact با نام **package-lock** ذخیره می‌کند. آن را دانلود و در ریشه‌ی مخزن آپلود کنید (Add file ← Upload files) تا نصب وابستگی‌ها در دفعات بعد دقیقاً ثابت و تکرارپذیر باشد (`npm ci`).
>
> پوشه‌ی `android` هم در هر اجرا با `npx cap add android` ساخته می‌شود. اگر خواستید آن را ثابت کنید، روی کامپیوتر یک بار `npx cap add android` بزنید و پوشه را به مخزن اضافه کنید.

## نصب APK روی گوشی

1. فایل `Nardbaz-Android.apk` را به گوشی منتقل کنید.
2. آن را لمس کنید. اگر اندروید پرسید، اجازه‌ی «نصب از منبع ناشناس» را برای همان برنامه (مرورگر یا مدیر فایل) فعال کنید.
3. **Install** را بزنید و برنامه‌ی «نردباز» را باز کنید.

## ساخت نسخه‌ی Release (امضاشده)

کلید امضا هرگز نباید در مخزن گذاشته شود. فقط از GitHub Secrets استفاده کنید:

1. یک کلید بسازید (روی کامپیوتر با Java):
   `keytool -genkey -v -keystore nardbaz.keystore -alias nardbaz -keyalg RSA -keysize 2048 -validity 10000`
2. فایل را به Base64 تبدیل کنید (ویندوز: `certutil -encode nardbaz.keystore out.txt`؛ لینوکس/مک: `base64 -w0 nardbaz.keystore`).
3. در GitHub: **Settings ← Secrets and variables ← Actions ← New repository secret** و این‌ها را بسازید:
   - `ANDROID_KEYSTORE_BASE64` (متن Base64)
   - `ANDROID_KEYSTORE_PASSWORD`
   - `ANDROID_KEY_ALIAS` (مثلاً `nardbaz`)
   - `ANDROID_KEY_PASSWORD` (اگر با رمز فایل فرق دارد)
4. در **Actions** روی **Run workflow** بزنید و گزینه‌ی **release** را تیک بزنید. خروجی `Nardbaz-Android-release.apk` است.

فایل کلید را در جای امنی نگه دارید؛ برای به‌روزرسانی‌های بعدی لازم است.

## تغییر نام و آیکون برنامه

- **نام برنامه:** در فایل `capacitor.config.json` مقدار `appName` را عوض کنید.
- **شناسه‌ی برنامه:** مقدار `appId` (مثلاً `ir.nardbaz.game`)؛ پس از انتشار تغییرش ندهید.
- **آیکون:** فایل `resources/icon.png` (۱۰۲۴×۱۰۲۴) و `resources/splash.png` (۲۷۳۲×۲۷۳۲) را با تصویر خودتان عوض کنید؛ گردش‌کار خودش آیکون‌های اندروید را می‌سازد.
